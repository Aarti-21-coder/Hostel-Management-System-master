# Hostel Management System

A C++ project developed to manage hostel activities such as student registration, room allocation, waiting lists and room availability.

The main focus of this project is implementing Data Structures and Algorithms to handle different hostel management operations.

## Features

- Student registration and record management
- Priority-based room allocation
- Waiting list management
- Room availability tracking
- Student search
- Undo operations

## Technologies Used

- C++
- Object-Oriented Programming
- Data Structures and Algorithms
- CMake

## Data Structures Implemented

The project includes implementations of:

- AVL Tree
- Binary Heap
- Bloom Filter
- B+ Tree

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Make sure C++ compiler and CMake are installed.
4. Run the Windows batch script:

```bash
run.bat
```

Alternatively, use the PowerShell script:

```powershell
.\run.ps1
```
